Here are some of the projects I have worked on. More details can be found in their respective GitHub repositories.

### Finite-Capacity System Simulator
**Repository**: [WaqasSwati/FCQ_OMNeTpp](https://github.com/muhammadwaqas01/FCQ_OMNeTpp)

This project is an open-source simulation framework designed to model and analyze resource allocation in large-scale, capacity-constrained computing systems, as developed during my doctoral research.


### MJQM-F OMNeT++
**Repository**: [WaqasSwati/MJQM-F_OMNeTpp](https://github.com/muhammadwaqas01/MJQM-F_OMNeTpp)

This project extends the queuing model framework to support multi-job queuing mechanisms and fairness-based resource allocation in OMNeT++, focusing on more complex scheduling policies.

---

### FCQ Performance Evaluation
**Repository**: [WaqasSwati/FCQ_Performance_Evaluation](https://github.com/muhammadwaqas01/FCQ_Performance_Evaluation)

This repository contains experiments and performance evaluation scripts for the Finite-Capacity Queueing (FCQ) models, including metrics such as dropping probability and energy consumption under different scheduling policies.
