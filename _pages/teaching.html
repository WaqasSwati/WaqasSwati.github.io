Teaching

I have taught and assisted several undergraduate and postgraduate courses, focusing on software engineering, formal methods, and human–computer interaction.

University of Lahore, Islamabad, Pakistan (2019–2021)

  • Software Engineering

    Explores the basics of software engineering, frameworks for software development, and different software process models.

  • Human Computer Interaction

    Focuses on user-centered interface design, usability principles, and evaluation methods for interactive systems.

  • Software Requirements and Specification

    Covers techniques for eliciting, documenting, and managing requirements to ensure high-quality software specifications.

  • Discrete Structures

    Provides mathematical foundations for computer science, including logic, sets, relations, and combinatorics.

IQRA National University, Peshawar, Pakistan (2017–2019)

  • Formal Methods in Software Engineering

    Introduces mathematical specification and verification techniques for modeling and validating software systems.

  • Enterprise Systems Engineering

    Provides an overview of enterprise resource planning and large-scale system integration concepts.
